# 性別事件處理流程表｜互動式手機網頁

依據使用者提供的 PDF《校園性別事件通報及調查處理程序參考流程圖（2025 年 1 月修／114 年 2 月 3 日修正）》整理的靜態互動網頁。採繁體中文、手機直式優先設計，可放到 GitHub Pages。

## 功能

- 手機優先的直式介面；桌面版提供左側固定個案清單。
- 新增、搜尋、切換、刪除個案；每案有獨立工作頁。
- 案號與個案狀態燈號：綠色正常、藍色警示、紅色逾期。
- 流程瀏覽與關鍵字檢索。
- 期限起算日期、期限日期、完成日期及備註欄位。
- 支援依起算日期計算期限、人工修改期限、標記完成並將完成日帶入下一階段。
- 個案狀態可選「未提出申請」「不申請」「送性平會審議」「結案」等。
- 使用瀏覽器 localStorage 儲存；可匯出全部個案或單一個案 JSON 備份。
- 可選擇啟用簡單提示音（瀏覽器通常需先有使用者操作才允許音效）。

## 專案架構

```text
gender-event-workflow/
├── index.html       # 完整互動網頁（HTML、CSS、JavaScript）
├── README.md        # 本說明文件
└── .nojekyll        # 可選；空白檔案，避免 GitHub Pages 套用 Jekyll
```

本專案不需要安裝 Node.js、套件或建置工具。

## 在電腦本機預覽

1. 下載 `index.html`。
2. 以 Chrome、Edge 或 Firefox 開啟。
3. 在側欄點「新增個案」開始使用。

## 上傳 GitHub 並啟用 GitHub Pages

1. 登入 GitHub，建立新的 repository，例如 `gender-event-workflow`。
2. 選擇 **Public** 或 **Private**。若要透過 GitHub Pages 公開瀏覽，請先確認帳號方案與 repository 設定允許 Pages。
3. 將 `index.html`、`README.md`（以及可選的 `.nojekyll`）上傳至 repository 根目錄。
4. 開啟 repository 的 **Settings → Pages**。
5. 在 **Build and deployment** 選擇 **Deploy from a branch**；Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
6. 等待部署完成，Pages 頁面會顯示網站網址。之後每次更新 `index.html` 並 push／commit，網站就會更新。

## 重要的個資與資安提醒

- **請勿將真實個案資料、姓名、身分資料、訪談內容、調查報告或任何可識別資訊放入公開 GitHub repository。**
- 網頁目前使用 `localStorage`，資料保存在當前瀏覽器／裝置，不會自動同步到其他承辦人，也不是加密的案件管理系統。清除瀏覽器資料、換裝置或使用無痕視窗，可能導致資料無法取回。
- 匯出的 JSON 備份可能包含案件資料，應存放於學校核准且有存取權限控管的位置，並依校內規定管理。
- 若要供多位承辦人共同使用，請改採經學校核准、具登入驗證、權限分級、加密、稽核紀錄及備份機制的系統；不建議直接將此靜態網頁當成正式個案資料庫。
- 本網站不會寄送通知、不會自動執行校安通報，也不會產生正式公文。

## 期限與法規使用說明

此網頁是**行政列管輔助工具，不是法律意見或法定期限計算器**。來源流程圖可辨識的節點包括：緊急通報、無管轄權時 7 日內移轉／通知、接獲申請調查或檢舉後 3 日節點、20 日內書面通知是否受理、不受理後 20 日內申復（以 1 次為限），以及流程圖所載部分情形 30 日申復等。實際起算點、工作日／日曆日、展延、例外及不同身分的救濟途徑，應依案件當時適用法規、主管機關最新規定及正式書面通知確認。

需求中提及的「1 個月＋1 個月」與「2 個月」在此設計為可編輯的內部列管階段，並非網頁自行認定的法定期限。建立案件後，請承辦人依實際案件與性平會決議設定起算日及到期日。

## 技術

- HTML5、CSS、原生 JavaScript
- 不使用外部 CDN、外部字型或第三方追蹤程式
- 瀏覽器儲存：`localStorage`
- 音效：Web Audio API（只有啟用音效後才播放簡短提示音）
